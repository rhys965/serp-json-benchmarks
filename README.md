## How Credit Multipliers Quietly Inflate Your Monthly Invoice

Every request to the Google SERP JSON endpoint consumes a fixed number of credits, regardless of how many result fields you actually use. Understanding the multiplier effect of those credits is the first step toward a predictable budget.

| Search Mode | Credits per Call | What you get |
|-------------|------------------|--------------|
| **Standard web search** (`serp: false`, `scrape: false`, `groundedAnswer: false`) | **2** | Organic results, ads, and a minimal metadata block. |
| **Full SERP JSON** (`serp: true`) | **2** | Structured JSON for page 1: organic results, ads, Google AI Overview, People Also Ask, related searches, local pack, news, images, popular products. |
| **Search + Scrape** (`scrape: true`) | **4** | All of the SERP JSON plus the rendered HTML of the top 1-10 result pages, JavaScript rendering, CAPTCHA handling, and anti-bot mitigation—all included in the base credit count. |
| **Grounded AI Answer** (`groundedAnswer: true`) | **5** | A concise answer generated by Google's LLM, complete with inline citations and source URLs. |

Because each mode's credit cost is *total*—the base 2 credits for a plain search are **not** added on top of the additional credits for scraping or AI answers—you can calculate exact monthly consumption by multiplying the number of calls by the per-call credit cost.

### Example: 10 k queries per month

*Scenario A – Standard search only*  
10,000 queries × 2 credits = 20,000 credits.  

*Scenario B – SERP + PAA extraction* (still 2 credits)  
10,000 queries × 2 credits = 20,000 credits – identical to Scenario A because the SERP mode does not add extra credits beyond the base cost.  

*Scenario C – SERP + Scrape*  
10,000 queries × 4 credits = 40,000 credits.  

*Scenario D – SERP + Grounded AI answer*  
10,000 queries × 5 credits = 50,000 credits.  

Now map those numbers to Geekflare's plan tiers (see the next section). The Starter plan gives you 10,000 credits per month, which comfortably covers Scenario A but would run out after just 2,500 queries in Scenario C. The Growth plan's 100,000 credits comfortably handles Scenario D with room to spare.  

When you compare against competitors, notice that many quote a dollar-per-thousand-credits figure that looks cheap until you factor in extra features like scraping, AI extraction, or proxy rotation. Geekflare's per-1K pricing is transparent **after** the credit cost is applied, so you never get a surprise multiplier hidden in a "premium" add-on.

## Plugging Geekflare Into AI Agents, MCP, and Automation Tools

**Official SDKs**

Both integrations automatically handle credit accounting by exposing a `credits_used` field on each response object.

## Quickstart Implementation You Can Drop Into Your Repo

Below are two minimal, runnable examples that hit the `POST https://api.geekflare.com/search` endpoint and request the full SERP JSON with People Also Ask extraction.

**Python (geekflare-api)**

```python
from geekflare_api import SearchClient

# Initialise the client with your API key
client = SearchClient(api_key="YOUR_API_KEY")

# Perform a SERP request with PAA and AI overview
payload = {
    "query": "how to build a resilient ETL pipeline",
    "serp": True,               # full SERP JSON, 2 credits total
    "device": "desktop",
    "city": "Berlin,Germany,Germany",
    "output": "json"
}

response = client.search(**payload)

# Example: print the first three People Also Ask items
for item in response.get("paa", [])[:3]:
    print(f"Q: {item['question']}")
    print(f"A: {item['answer']}\n")
```

**Node.js ( @geekflare/api-node )**

```js
const { SearchClient } = require("@geekflare/api-node");

// Create a client instance
const client = new SearchClient({ apiKey: "YOUR_API_KEY" });

async function run() {
  const result = await client.search({
    query: "best practices for rate-limit handling",
    serp: true,          // full SERP JSON, 2 credits total
    device: "mobile",
    city: "Sydney,New South Wales,Australia",
    output: "json"
  });

  // Log the AI Overview text and first two PAA entries
  console.log("AI Overview:", result.data.ai_overview.text);
  result.data.paa.slice(0, 2).forEach(p => {
    console.log(`Q: ${p.question}`);
    console.log(`A: ${p.answer}\n`);
  });
}

run().catch(console.error);
```

Both snippets respect the active plan's rate limit automatically; the SDKs will throttle if you exceed the per-second quota. You can also enable `max_retries: 3` in the client configuration to let the SDK retry on transient 5xx errors—those retries cost **zero** credits.

## Frequently Asked Questions

**What happens if I exceed my credit limit mid-run?**  
When you hit 100% of your allocated credits, the API returns a `429 Too Many Requests` error and pauses further processing. You can either upgrade to a higher tier or apply a one-time credit pack; the pause lifts automatically once additional credits are available.

**Can I use the API without a credit card?**  
Yes. The Free tier requires no credit card and gives you 500 credits each month. All paid tiers require a card for subscription billing.

**Is the proxy rotation included automatically?**  
Rotating proxy access is bundled with every paid plan and consumes an additional 4 credits per month. The Free tier does not have proxy access.

**Do failed 5xx responses count against my credit balance?**  
No. Any request that results in a server-side error (5xx) or a capture failure does **not** deduct credits, which makes retry loops cheap.

**How do I monitor credit usage in real time?**  
The Geekflare console displays a live credit counter and sends an email alert at 90% consumption. You can also query the `/usage` endpoint (documented in the API reference) to pull the current balance into your own monitoring dashboard.
